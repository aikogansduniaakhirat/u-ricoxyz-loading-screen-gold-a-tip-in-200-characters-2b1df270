One loading-screen tip, at most 200 characters, written for stressed developers
and AI coding agents at the same time. The tip is assembled from three parts in
`main.ts` — the register, the fault both parties share, and the turn — and the
program asserts every criterion the house judge weighs before writing: it opens
as a tip, it names the agent and the reader, it is one line, and it avoids the
worn coffee/deadline/compile subjects.

The entry it ships:

> Tip: 'done' means the agent stopped typing, 'definitely done' means it stopped reading, and you believe both. Open the file anyway.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.txt` (131 characters, no trailing newline).
